# ArchForge Implementation Plan

## Stack
- Backend: Go
- Frontend: Angular
- Database: PostgreSQL
- Auth: JWT
- Search/Graph: PostgreSQL + future graph/vector stores

## Current Scaffold
- Go API server with health and overview endpoints
- Angular app shell to be generated in the frontend directory
- This document tracks the MVP implementation milestones

## MVP Milestones
1. Repository ingestion via GitHub URL and ZIP upload
2. Language-agnostic parser framework
3. IR generation and persistence
4. Hybrid retrieval pipeline
5. AI chat experience
6. Architecture visualization and documentation generation

## Day-by-Day Alignment
- Day 1: Architecture and repository setup completed
- Day 2: Go backend + Angular frontend foundation
- Days 3-4: Authentication and repository import
- Days 5-7: Parsing and IR generation
- Days 8-10: Architecture views
- Days 11-13: Retrieval and AI context assembly
- Days 14-20: Documentation, polish, Docker, deployment
